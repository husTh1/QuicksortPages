# Quicksort – Interactive Walkthrough

شرح تفاعلي خطوة بخطوة لخوارزمية Quicksort (Partition + Recursion).

**شرح المبرمج حسين محمد جليل · Dev.Hussein Mohammed**

## المميزات
- حل المثال من البداية: pivot ثم low/high ثم i ثم جدول التتبع صف بصف
- أسئلة تفاعلية قبل كل مقارنة، وعدّاد نتيجة
- حل مصفوفتك الخاصة (2 إلى 15 رقم)
- إكمال الحل لين تنرتب المصفوفة، مع شجرة الاستدعاءات
- وضع نهاري وليلي، وضع عرض كبير، تشغيل تلقائي
- متجاوب مع الموبايل والآيباد والحاسبة

## النشر على GitHub Pages
1. أنشئ Repository جديد (مثلاً `quicksort-demo`) واجعله Public.
2. ارفع محتويات هذا المجلد (`index.html` و `.nojekyll` و `README.md`) إلى الفرع `main`.
3. من **Settings → Pages**: اختر Source = **Deploy from a branch**، الفرع `main`، المجلد `/ (root)`، ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/quicksort-demo/`

## التشغيل محلياً
افتح `index.html` مباشرة بأي متصفح. لا يحتاج إنترنت ولا تثبيت.
